# Overview

This project is a simple introductory software program that prints “Hello World” to the terminal. It demonstrates the basics of programming, version control using Git, and repository management using GitHub.

The goal of this project is to strengthen my understanding of how software is created, stored, and shared in a professional development environment.

The program serves as a foundation for learning how to build and structure future software applications.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

This project was developed using the following tools:
- Visual Studio Code
- Git and GitHub
- Linux terminal (Kali Linux)

Programming Language:
- Python 3

Python was used because it is simple, widely used, and ideal for learning programming fundamentals such as syntax, execution flow, and output handling.
